# Aurawill Website Content Generation Prompts

Complete set of production-ready prompts for generating unique website content for Aurawill Health Mix brand.

## Quick Start

1. **Individual Sections**: Use numbered prompt files (01-11) for specific sections
2. **Complete Website**: Use `MASTER-PROMPT.md` for all content at once
3. **Images**: Use `10-image-generation.md` for visual content

## File Structure

- `01-hero-banner.md` - Main landing section
- `02-product-section.md` - Product details and pricing
- `03-benefits-section.md` - Before/after benefits
- `04-reviews-section.md` - Customer testimonials
- `05-why-choose-us.md` - 3-card value proposition
- `06-ingredients-gallery.md` - Complete ingredient list
- `07-recipe-section.md` - Usage recipes
- `08-our-story.md` - Brand story page
- `09-multilingual.md` - Translation prompts
- `10-image-generation.md` - Visual content prompts
- `11-footer-policies.md` - Legal and policy content
- `MASTER-PROMPT.md` - Complete website generator

## Brand Guidelines

- **Tone**: Warm, family-focused, trustworthy
- **Target**: Indian families, teenagers, elders  
- **Product**: 900g health mix, ₹300, 36+ natural ingredients
- **Values**: Traditional preparation, no preservatives, family nutrition

## Usage

Copy any prompt and paste into ChatGPT, Claude, or other AI content generators to create original, brand-consistent content.
